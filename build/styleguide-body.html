Voice

Plain-spoken and specific. State the outcome and the reason, never the hype. Sentence case everywhere except mono eyebrows and short labels. Every page, document, and deck ends with exactly one next action.

02 · Foundations

Color

Cobalt is structure. Spice is heat. No new hues, no gradients, flat fills only.

Primitives

Raw ramps. Pages never reference these — they reference the semantic roles below, which pick a step per mode.

Semantic roles — live in the current mode

What each token does, its resolved value right now, and its WCAG contrast against the page and card surfaces. Toggle the theme in the masthead to re-check.

The two jobs

Cobalt is structure: surfaces, headings, eyebrows, rules, table headers, the emphasized data series. Spice is heat: links, the primary button, focus rings, the one "look here" moment. Spice never colors body text, headings, or large fills — if everything is spicy, nothing is.

05 · Foundations

Themes

Dark is the default. Light is a designed mode, not an inversion.

How it resolves

:root carries the dark set. @media (prefers-color-scheme: light) and [data-theme="light"] carry the light set; [data-theme="dark"] pins dark. The toggle writes data-theme on <html> and remembers it per browser; the script runs before paint, so there is no flash.

What stays dark in both modes

Masthead, footer, code blocks, tooltips, covers — on --sc-ink. That shared spine is what makes a light page recognisably the same product as its dark sibling.

Asking price, plus shipping when the car is outside the region, adjusted for mileage against a baseline.

Categorical bars

Listings by state, per week. Slots 1–5 in order, ≤24px thick, 4px rounded data-ends, 2px surface gap.

Rules

One y-axis, always. Color follows the entity, never its rank. Status colors are never a series. Legend for two or more series; direct-label selectively. Text wears text tokens, never the series color. Every chart has a table twin. All-pairs forms (scatter, bubble, maps) use slots 1–3 only.

08 · Build

The mark

The chick — locked August 2026. Wine head, teardrop flame, file-fold corner, cream face. It is the one mark for everything: every project wears it in the masthead and favicon, with the project's name set beside it in type.

The four forms

Sizes

Usage

Color-dark on ink and dark surfaces, color-light on white and cream, mono for the watermark and one-color uses. Files in assets/: four mark SVGs, the avatar tile, lockups (SVG + PNG), favicon set. Clear space ≥ the flame's height on all sides. Never recolor, outline, rotate, or add effects.

Watermark spec

Mono mark 20px tall + wordmark in the display face at 12px, footer-right, 70% opacity, links to the profile. The masthead shows the color form; the watermark shows the mono form. One chick per surface, always the same sizes.

09 · Ship

Pre-ship checklist

Open the style guide beside the page. If something on the page has no equivalent here, it's a new component — fold it in or take it out.

  1. Masthead: project mark + name left, theme toggle right, --sc-ink in both modes.
  2. Title block opens with an eyebrow; h1 is one plain sentence; dek is one sentence.
  3. Exactly one spice action per view (primary button or next-action callout).
  4. At most one core callout per section.
  5. Page CSS references semantic tokens only — no hex, no primitives.
  6. Charts use --sc-chart-*; one y-axis; legend for ≥2 series; a table twin under each.
  7. Text never wears a chart or accent color; deltas carry ▲▼; chips carry words.
  8. Screenshotted at 1280 and 390 in dark and light; nothing scrolls sideways.
  9. Footer has the source line and the watermark; favicon is the project mark.
  10. Page ends with one next action, not a list.
10 · Ship

Do / don't

Do

  • Lead with a lowercase "//" eyebrow.
  • Keep the masthead and footer dark in both modes.
  • Put the chick in the masthead and the watermark; name the project in type.
  • Use Instrument Sans for numbers, proportional figures.
  • Separate with hairlines and color, not shadow.
  • Write the outcome and the reason.

Don't

  • Add a hue or a gradient.
  • Use spice for text, headings, or large fills.
  • ALL-CAPS a tracked label — lowercase mono is the house style.
  • Use a display face or tabular figures for a big number.
  • Ship an icon set without noting the substitution.
  • End with a menu of next steps.
